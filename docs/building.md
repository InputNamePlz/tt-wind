# Building tt-wind

## Prerequisites

- Visual Studio 2022 Build Tools (MSVC v143) — full VS not required
- Windows Driver Kit 10 with MSBuild integration (the
  `WindowsKernelModeDriver10.0` platform toolset and
  `C:\Program Files (x86)\Windows Kits\10\build\`)

The project pins `WindowsTargetPlatformVersion` 10.0.26100.0 and builds a
KMDF driver for x64 Windows 10 1709+.

## Build

From a normal shell (no special environment needed — the WDK toolset
resolves its own paths):

```powershell
& "C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe" `
    ttwind.sln /p:Configuration=Release /p:Platform=x64 /p:SkipPackageVerification=true /m
```

`SkipPackageVerification=true` skips the InfVerif step because this
machine's WDK install is missing `InfVerif.dll`; drop the flag on a WDK
install that has it. Use `/p:Configuration=Debug` for a debug build.

Outputs land in `x64\Release\`:

- `ttwind.sys`, `ttwind.pdb` — the driver
- `ttwind\` — the driver package: stamped `ttwind.inf`, `ttwind.sys`,
  and the `ttwind.cat` catalog generated by inf2cat (10_X64).

## Test signing

Create a self-signed code-signing certificate once, then sign both the
driver and the catalog in the package directory:

```powershell
$cert = New-SelfSignedCertificate -Type CodeSigningCert `
    -Subject "CN=TTWind Test Signing" -CertStoreLocation Cert:\CurrentUser\My
$signtool = "C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe"
& $signtool sign /fd sha256 /sha1 $cert.Thumbprint /s My `
    x64\Release\ttwind\ttwind.sys x64\Release\ttwind\ttwind.cat
```

`signtool verify /v /pa` will report the signature but an untrusted
chain until the certificate is installed on the test machine (see
below); that is expected for a build-only box.

## Installing on a test machine (not done by the build)

1. Enable test signing and reboot: `bcdedit /set testsigning on`
2. Trust the test certificate (exported `.cer`):
   `certutil -addstore Root ttwind-test.cer` and
   `certutil -addstore TrustedPublisher ttwind-test.cer`
3. Stage/install the package:
   `pnputil /add-driver x64\Release\ttwind\ttwind.inf /install`

If the device is currently bound to another vendor's driver, that
driver must be replaced explicitly (Device Manager "Update driver", or
`pnputil /delete-driver oemNN.inf /uninstall` for the old package)
before or after installing this one.
